# Welcome to DLS2
In modern robotic systems, scalable, flexible, and robust software architectures are critical for enabling efficient collaboration and computation across distributed hardware. DLS2 is a  a truly distributed robot-centric software architecture designed for complex, highly dynamic robots.

%This is the current stage of development of DLS2, whose main design paradigm is explained in the paper _D. Wildgrube Bertol, G. Fink, M. Marchitto, Y. Nisticò, M. Pestarino, and C. Semini, “DLS2: A distributed microcomponent-based robotic software architecture”_, which is under review.
